# Changelog

## 1.0.0 — 2026-10-17

Initial scoped release of the local CSV reconciliation CLI and Python API.

- Strict source mappings, date/encoding/sign configuration, and row-specific input validation.
- Exact integer minor-unit money with explicit currency precision.
- Conservative one-to-one matching; ambiguity, duplicate content, zero values, and tolerated differences stay in review.
- Portable HTML/CSV/JSON outputs, source hashes, per-currency controls, and generated-file checksums.
- Synthetic demo, behavioral tests, package build, and GitHub Actions workflow.

No FX conversion, PDF/XLSX input, split settlements, persistent approvals, or accounting entries. No production adoption or user time-savings claims.
